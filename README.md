# 和暦・西暦変換

和暦（元号）と西暦（グレゴリオ暦）を相互変換するPWAアプリ。

## 機能

- **キーボード入力**: テキストボックスに日付を入力してEnterまたは変換ボタンを押す
- **音声入力**: マイクボタンを押して話す。「令和６年１２月３日は」のように「は」で終わると自動変換
- **自動判定**: 和暦・西暦を自動的に判定
- **3タイプ対応**: 年のみ / 年月 / 年月日

## 対応元号

明治・大正・昭和・平成・令和

## 入力例

| 入力 | 出力 |
|------|------|
| 令和6年12月3日 | 2024年12月3日 |
| 2024/12/3 | 令和6年12月3日 |
| 昭和64年1月7日 | 1989年1月7日 |
| 1989年1月8日 | 平成1年1月8日 |
| 令和元年 | 2019年 |
| 2019 | 令和1年 / 平成31年 |

## 技術

- Vanilla HTML/CSS/JS（ビルド不要）
- Web Speech API（音声入力）
- Service Worker（オフライン対応）
- PWA対応（ホーム画面に追加可能）

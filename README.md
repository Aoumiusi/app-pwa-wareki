# 和暦・西暦変換

和暦（元号）と西暦（グレゴリオ暦）を相互変換するPWAアプリ。

## 機能

- **リアルタイム変換**: 入力のたびに即時変換
- **キーボード入力**: テキストボックスに入力してEnterまたは変換ボタンを押す
- **音声入力**: マイクボタンを押して話す。「令和６年１２月３日は」のように末尾を「は」で終えると自動変換
- **自動判定**: 和暦・西暦を自動判定して相互変換
- **粒度対応**: 年のみ / 年月 / 年月日の3粒度
- **複数候補表示**: 元号をまたぐ年（例: 2019年）は複数の和暦を並列表示
- **元号終了年超え対応**: 「昭和100年」のような架空の年も変換可

## 対応元号

明治・大正・昭和・平成・令和

## 入力フォーマット

### 和暦 → 西暦

| フォーマット | 例 |
|---|---|
| 元号 + 年月日（漢字） | `令和6年12月3日` `令和6年` `昭和64年1月7日` |
| 元号 + 区切り文字（`.` `/`） | `令和6.12.3` `平成30/3/15` |
| 元号略称（大文字・小文字不問） + 年月日 | `R6年12月3日` `H30年1月1日` |
| 元号略称 + 区切り文字 | `R6.12.3` `H30/1/8` `r.6/12/3` |
| 元年表記 | `令和元年5月1日` `R.元` |
| 全角数字 | `令和６年１２月３日` |

略称対応表: R=令和 / H=平成 / S=昭和 / T=大正 / M=明治

### 西暦 → 和暦

| フォーマット | 例 |
|---|---|
| 年月日（漢字） | `2024年12月3日` `2024年` |
| スラッシュ区切り | `2024/12/3` `2024/12` |
| ハイフン区切り | `2024-12-3` `2024-12` |
| 年のみ | `2024` |

## 変換例

| 入力 | 出力 |
|---|---|
| `令和6年12月3日` | 2024年12月3日 |
| `R6.12.3` | 2024年12月3日 |
| `2024/12/3` | 令和6年12月3日 |
| `昭和64年1月7日` | 1989年1月7日 |
| `1989年1月8日` | 平成1年1月8日 |
| `令和元年` | 2019年 |
| `2019` | 令和1年 / 平成31年（複数候補） |
| `昭和100年` | 2025年（元号終了年超え） |

## 技術

- Vanilla HTML/CSS/JS（依存ライブラリなし、ビルド不要）
- Web Speech API（音声入力）
- Service Worker（オフライン対応）
- PWA対応（ホーム画面に追加可能）
